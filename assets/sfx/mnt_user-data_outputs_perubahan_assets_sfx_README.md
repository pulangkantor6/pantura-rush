# SFX

Taruh berkas di folder ini. Format `.ogg` (diutamakan) atau `.mp3`. Tanpa berkas, game memakai suara sintetis bawaan.

| Nama berkas | Dipakai saat |
|---|---|
| `horn` | klakson standar |
| `horn_strong` | klakson setelah di-upgrade |
| `crash` | tabrakan (pemain dan antar kendaraan NPC) |
| `coin` | koin biasa |
| `coin_gold` | koin emas (bernilai 5) |
| `siren_hi`, `siren_lo` | sirene ambulance, dua nada bergantian |
| `warn` | peringatan pom bensin atau bengkel |

Contoh: `assets/sfx/horn.ogg`. Pastikan lisensi tiap berkas sesuai (mis. CC0) dan catat sumbernya di berkas `CREDITS.md`.
