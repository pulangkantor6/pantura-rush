# Musik

Format `.ogg` (diutamakan) atau `.mp3`. Semua trek diputar berulang (loop), jadi siapkan ujung yang menyambung mulus.

| Nama berkas | Dipakai saat |
|---|---|
| `menu` | menu awal dan layar tamat |
| `day` | siang dan senja |
| `night` | malam hari |

Berpindah antara `day` dan `night` memakai transisi halus. Tanpa berkas, musik tidak diputar. Catat sumber dan lisensi di `CREDITS.md`.
