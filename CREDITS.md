# Kredit dan lisensi aset

Kode game berlisensi MIT (lihat `LICENSE`). **Aset di bawah ini punya lisensi sendiri.**
Isi kolom "Sumber / Lisensi" sebelum repo dipublikasikan, supaya jelas aset boleh didistribusikan ulang.

| Aset | Berkas | Sumber / Lisensi |
|---|---|---|
| Musik menu, siang, malam, peringatan BBM | `assets/music/*.mp3` | (isi) |
| SFX klakson, gas, rem, koin, tabrakan, sirene, peringatan, beli | `assets/sfx/*.mp3` | (isi) |
| Video dan gambar latar menu | `assets/menu/bg_menu.mp4`, `bg_menu.jpg` | (isi) |
| Ikon kendaraan, tombol, toko, speedometer | `icons/*.png` | (isi) |
| Font "Black Ops One" dan "Russo One" | dimuat dari Google Fonts | SIL Open Font License 1.1 |

Catatan: `coin_gold.mp3` dibuat dari `coin.mp3` dengan nada dinaikkan; ikuti lisensi `coin.mp3`.
